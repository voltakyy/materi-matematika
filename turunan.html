Bagian 1 · Konsep

Apa Itu Turunan?

Turunan fungsi di suatu titik adalah gradien garis singgung kurva di titik tersebut. Konsep ini lahir dari limit: saat dua titik pada kurva saling mendekat, garis secan berubah menjadi garis singgung.

Garis secan AB → garis singgung saat h → 0 m tangen = 2.00
gradien secan = 2.00 gradien tangen = 2.00
Untuk f(x) = x², gradien secan = 2x + h. Semakin kecil h, semakin dekat nilainya ke 2x.

Dari Secan ke Tangen

Misalkan kita punya kurva f(x). Dua titik A(x, f(x)) dan B(x + h, f(x + h)) dihubungkan oleh garis secan. Gradiennya adalah [f(x+h) − f(x)] / h.

Ketika B digeser mendekati A (h → 0), garis secan berubah menjadi garis singgung di A. Nilai limit gradien secan itulah yang disebut turunan.

f'(x) = limh→0 [ f(x + h) − f(x) ] / h

Notasi lain yang sering dipakai: y', dy/dx, dan Dx f(x).

Menghitung Turunan dari Definisi

Contoh: f(x) = x²

  1. Substitusi f(x+h) = (x+h)² = x² + 2xh + h²
  2. Selisih f(x+h) − f(x) = 2xh + h²
  3. Bagi h (2xh + h²)/h = 2x + h Pembagian ini sah karena h ≠ 0 — h hanya mendekati 0, bukan sama dengan 0.
  4. Limit Ambil h → 0: f'(x) = 2x

Cek: di x = 3, gradien garis singgung = 6. Geser slider di samping untuk memverifikasi secara visual.

📐 Sebagai gradien

f'(a) adalah kemiringan garis singgung kurva di x = a. Nilai positif berarti kurva sedang menanjak, negatif berarti menurun.

⏱️ Sebagai laju perubahan

Turunan menjawab “seberapa cepat sesuatu berubah”. Jika s(t) posisi, maka s'(t) adalah kecepatan pada saat t.

🔍 Sebagai aproksimasi

Di sekitar titik singgung, kurva mirip garis lurusnya. Karena itu f(x+h) ≈ f(x) + f'(x)·h untuk h kecil.

Bagian 2 · Aturan Turunan

Rumus Turunan Fungsi Aljabar

Hafalkan pola dasarnya, lalu kenali aturan untuk operasi yang lebih kompleks. Klik kartu rumus untuk menandai bahwa Anda sudah memahaminya.

Aturan Bentuk umum Contoh
Konstanta f(x) = c  →  f'(x) = 0 f(x) = 7 → f'(x) = 0
Identitas f(x) = x  →  f'(x) = 1 f(x) = x → f'(x) = 1
Pangkat f(x) = xn  →  f'(x) = n·xn−1 f(x) = x5 → f'(x) = 5x4
Kelipatan konstan f(x) = c·u(x)  →  f'(x) = c·u'(x) f(x) = 3x4 → f'(x) = 12x3
Jumlah / selisih f(x) = u ± v  →  f' = u' ± v' f(x) = x3 + 2x → 3x2 + 2
Perkalian f(x) = u·v  →  f' = u'v + uv' f(x) = x2(3x+1) → 9x2 + 2x
Pembagian f(x) = u/v  →  f' = (u'v − uv') / v2 f(x) = (3x−1)/(x+2) → 7/(x+2)2
Aturan rantai h(x) = f(g(x))  →  h' = f'(g(x))·g'(x) h(x) = (2x+1)4 → 8(2x+1)3
Pangkat rasional / negatif f(x) = xm/n  →  f' = (m/n)·xm/n − 1 f(x) = √x → 1/(2√x)

Bentuk Akar & Pecahan

Ubah dulu ke bentuk pangkat, baru gunakan aturan pangkat. Ini trik yang menyelamatkan banyak soal.

Akar kuadrat √x = x1/2 → 1/(2√x) Berlaku untuk x > 0.
Akar pangkat n n√x = x1/n → (1/n)x1/n − 1 Contoh: 3√x → (1/3)x−2/3.
Pecahan 1/x 1/x = x−1 → −1/x2 Pangkat negatif diturunkan seperti biasa.
Pecahan 1/x² 1/x2 = x−2 → −2/x3 Turunkan pangkat, lalu kurangi satu.

Membaca Aturan Rantai

Aturan rantai dipakai saat ada “fungsi di dalam fungsi”. Turunkan bagian luar (dengan isi tetap), lalu kalikan dengan turunan bagian dalam.

h(x) = (2x + 1)4
h'(x) = 4(2x + 1)3 · 2 = 8(2x + 1)3

Jebakan paling umum: lupa mengalikan turunan fungsi dalam. Tanpa “· 2”, jawabannya salah.

Contoh Cepat

Turunan f(x) = 3x4 − 2x2 + 5x − 7 adalah f'(x) = 12x3 − 4x + 5. Konstanta −7 hilang karena turunannya 0.

Bagian 3 · Teknik

Contoh Dikerjakan Bertahap

Klik setiap contoh untuk membuka langkah pengerjaan. Pola yang sama dipakai berulang kali — setelah tiga atau empat contoh, sebagian besar soal akan terasa familiar.

Cara membaca langkah: langkah biasa langkah kunci (sering dilewatkan) hasil / jawaban jebakan & cek ulang
1. Polinomial: f(x) = 3x⁴ − 2x² + 5x − 7
  1. AturanTurunkan tiap suku satu per satu.
  2. Pangkat 3x4 → 3 · 4x3 = 12x3 Pangkat dikalikan ke depan (4 × 3), lalu pangkatnya dikurangi satu.
  3. Pangkat−2x2 → −2 · 2x = −4x
  4. Konstanta5x → 5 dan −7 → 0
Jawaban: f'(x) = 12x3 − 4x + 5
2. Aturan rantai: f(x) = (2x + 1)⁴
  1. KenaliFungsi luar: ( )⁴. Fungsi dalam: 2x + 1.
  2. Turunkan luar 4(2x + 1)3 Isi di dalam kurung tetap ditulis apa adanya.
  3. Turunkan dalamd/dx(2x + 1) = 2
  4. Jangan lupaKalikan kedua hasil. Jebakan utamanya: tanpa “· 2”, jawaban 4(2x+1)³ masih salah.
Jawaban: f'(x) = 4(2x + 1)3 · 2 = 8(2x + 1)3
3. Aturan perkalian: f(x) = x²(3x + 1)
  1. Misalkan u = x2 (u' = 2x) dan v = 3x + 1 (v' = 3).
  2. Rumus f' = u'v + uv' Turunan perkalian bukan u'·v'. Dua suku harus dijumlahkan.
  3. Substitusi= 2x(3x + 1) + x2(3)
  4. Sederhanakan= 6x2 + 2x + 3x2
Jawaban: f'(x) = 9x2 + 2x

Alternatif: jabarkan dulu f(x) = 3x3 + x2, lalu turunkan → 9x2 + 2x. Hasilnya sama.

4. Aturan pembagian: f(x) = (3x − 1)/(x + 2)
  1. Misalkan u = 3x − 1 (u' = 3) dan v = x + 2 (v' = 1).
  2. Rumusf' = (u'v − uv') / v2
  3. Jebakan Penyebut harus dikuadratkan: (x + 2)2. Banyak yang menulis pembagi (x+2) saja — itu salah.
  4. Substitusi= [3(x + 2) − (3x − 1)·1] / (x + 2)2
  5. Sederhanakan= (3x + 6 − 3x + 1) / (x + 2)2
Jawaban: f'(x) = 7 / (x + 2)2
5. Akar + rantai: f(x) = √(4x + 5)
  1. Ubah bentuk√(4x + 5) = (4x + 5)1/2
  2. Turunkan luar½(4x + 5)−1/2
  3. Turunkan dalamd/dx(4x + 5) = 4
  4. Kalikan½ · 4 = 2
Jawaban: f'(x) = 2 / √(4x + 5)
6. Rantai dua lapis: f(x) = (x² + 3x)⁵
  1. KenaliLuar ( )⁵, dalam x2 + 3x.
  2. Turunkan luar5(x2 + 3x)4
  3. Turunkan dalam2x + 3
Jawaban: f'(x) = 5(x2 + 3x)4(2x + 3)

Bagian 4 · Penerapan

Di Mana Turunan Digunakan?

Turunan bukan hanya alat menghitung. Ia dipakai untuk membaca bentuk grafik, mencari nilai optimum, dan mengukur laju perubahan.

Cara membaca langkah: langkah biasa langkah kunci (sering dilewatkan) hasil / jawaban jebakan & cek ulang

1 Garis Singgung & Garis Normal

Gradien garis singgung kurva y = f(x) di titik x = a adalah m = f'(a). Persamaannya:

y − f(a) = f'(a) · (x − a)

Garis normal adalah garis yang tegak lurus garis singgung di titik yang sama, sehingga gradiennya −1 / f'(a).

Contoh: f(x) = x² − 4x + 3 di x = 3
  1. Nilai fungsi f(3) = 9 − 12 + 3 = 0 → titik singgung (3, 0).
  2. Turunan f'(x) = 2x − 4 Turunan ini belum jadi jawaban — ia baru “mesin” untuk mencari gradien.
  3. Gradien Substitusi x = 3: m = f'(3) = 2. Inilah inti soal garis singgung: angka 2 adalah gradien yang dipakai di persamaan garis.
  4. Susuny − 0 = 2(x − 3)
  5. Normal Gradien normal −1/2, bukan 2. Karena tegak lurus: m normal = −1/f'(3). Cek: 2 × (−½) = −1 ✔
Jawaban:
Garis singgung: y = 2x − 6
Garis normal: y = −½(x − 3) = −½x + 1,5

2 Fungsi Naik & Fungsi Turun

Tanda turunan pertama memberi tahu arah grafik: f'(x) > 0 → fungsi naik; f'(x) < 0 → fungsi turun; f'(x) = 0 → kandidat titik stasioner.

Contoh: f(x) = x³ − 3x

  1. Turunan f'(x) = 3x2 − 3 = 3(x − 1)(x + 1) Bentuk faktor memudahkan melihat kapan f'(x) = 0.
  2. Titik kritisPembuat nol: x = −1 dan x = 1.
  3. Uji tanda Ambil satu nilai x di tiap daerah, lalu tentukan tanda f'(x). Tanda turunan inilah yang menentukan naik atau turun — bukan nilai f(x).
Intervalx < −1−1 < x < 1x > 1
Tanda f'(x)+−+
Sifatnaikturunnaik
Jawaban: naik pada x < −1 atau x > 1; turun pada −1 < x < 1.

Simulasi Naik / Turun

Warna garis: teal = naik, merah = turun, titik emas = stasioner.

3 Titik Stasioner & Uji Turunan Kedua

Titik stasioner terjadi saat f'(x) = 0. Jenisnya ditentukan oleh turunan kedua:

UjiKesimpulanBentuk grafik
f''(a) < 0Maksimum lokal di x = aPuncak (∩)
f''(a) > 0Minimum lokal di x = aLembah (∪)
f''(a) = 0Uji tidak konklusifPerlu uji tanda f'

Contoh: f(x) = x³ − 3x

  1. Cari stasioner f'(x) = 3x2 − 3 = 0 → x = ±1
  2. Turunan kedua f''(x) = 6x, lalu substitusi: f''(−1) = −6 dan f''(1) = 6. Turunkan f'(x) sekali lagi, baru masukkan nilai x stasioner.
  3. Simpulkan f'' < 0 → maksimum; f'' > 0 → minimum.
Jawaban:
f(−1) = 2 → maksimum lokal di (−1, 2)
f(1) = −2 → minimum lokal di (1, −2)

Hati-hati: f'(x) = 0 tidak selalu berarti maksimum atau minimum. Contoh f(x) = x³: f'(0) = 0, tetapi f''(0) = 0 dan grafiknya tetap naik — itu titik belok, bukan titik ekstrem.

4 Nilai Maksimum & Minimum pada Interval Tertutup

Pada interval [a, b], nilai maksimum/minimum bisa terjadi di titik stasioner atau di kedua ujung interval. Karena itu, selalu periksa keduanya.

Contoh: f(x) = x³ − 3x pada [−2, 2]

  1. Stasioner f'(x) = 3x2 − 3 = 0 → x = ±1
  2. Ujung interval Hitung nilai di semua kandidat: f(−2) = −2, f(−1) = 2, f(1) = −2, f(2) = 2. Nilai ekstrem pada interval tertutup bisa terjadi di ujung interval, bukan hanya di titik stasioner.
  3. Bandingkan Pilih nilai terbesar dan terkecil dari seluruh kandidat.
Jawaban:
Nilai maksimum = 2 (di x = −1 dan x = 2)
Nilai minimum = −2 (di x = −2 dan x = 1)

Perhatikan: nilai maksimum juga muncul di ujung interval x = 2. Kalau hanya memeriksa titik stasioner, kesimpulannya bisa kurang lengkap.

5 Laju Perubahan & Kinematika

Jika s(t) menyatakan posisi benda pada waktu t, maka:

kecepatan v(t) = s'(t)   |   percepatan a(t) = v'(t) = s''(t)

Contoh: s(t) = t³ − 6t² + 9t meter, t dalam detik.

  1. Kecepatan v(t) = s'(t) = 3t2 − 12t + 9 = 3(t − 1)(t − 3) Kecepatan adalah turunan pertama dari posisi.
  2. Percepatana(t) = v'(t) = 6t − 12
  3. Berhenti Benda berhenti sesaat saat v(t) = 0 → t = 1 atau t = 3. “Berhenti” berarti kecepatan nol, bukan percepatan nol.
s(1) = 4 m, v(1) = 0
s(3) = 0 m, v(3) = 0
v(0) = 9 m/s, v(2) = −3 m/s
a(2) = 0 m/s²

Kecepatan negatif berarti benda bergerak ke arah berlawanan.

6 Ekonomi: Biaya Marginal

Jika C(x) adalah total biaya memproduksi x unit, maka C'(x) adalah biaya marginal — perkiraan biaya tambahan untuk memproduksi satu unit lagi.

Misal C(x) = 0,02x3 − 0,6x2 + 50x + 1000 (dalam ribu rupiah). Berapa biaya marginal pada x = 10?

  1. Turunkan C'(x) = 0,06x2 − 1,2x + 50 Biaya marginal adalah turunan dari biaya total — bukan biaya totalnya dibagi x.
  2. Substitusi C'(10) = 0,06(100) − 1,2(10) + 50
  3. Hitung = 6 − 12 + 50 = 44
Jawaban: C'(10) = 44 ribu rupiah per unit

Artinya, sekitar 44 ribu rupiah tambahan untuk memproduksi unit ke-11.

Bagian 5 · Latihan Mandiri

Coba Dulu, Baru Lihat Pembahasan

Kerjakan di kertas terlebih dahulu. Buka pembahasan hanya setelah Anda mendapatkan jawaban sendiri — ini jauh lebih efektif daripada membaca solusi langsung.

Penanda warna sama seperti bagian sebelumnya: emas = langkah kunci, hijau = hasil, merah = jebakan.

Soal 1 — Turunkan f(x) = 2x⁵ − 3x² + 7x

Aturan: pangkat, kelipatan, jumlah/selisih.

  1. Pangkat2x5 → 2 · 5x4 = 10x4
  2. Pangkat−3x2 → −3 · 2x = −6x
  3. Konstanta7x → 7
Jawaban: f'(x) = 10x4 − 6x + 7

Periksa urutan pangkatnya: 5 → 4, lalu 2 → 1. Suku konstanta akan menjadi 0.

Soal 2 — Turunkan f(x) = (3x − 2)⁵
  1. KenaliFungsi luar ( )5, fungsi dalam 3x − 2.
  2. Turunkan luar 5(3x − 2)4 Isi kurung tidak diubah dulu pada langkah ini.
  3. Jangan lupa Kalikan dengan turunan dalam: · 3. Tanpa faktor 3, jawaban masih belum selesai.
Jawaban: f'(x) = 5(3x − 2)4 · 3 = 15(3x − 2)4
Soal 3 — Turunkan f(x) = (x² + 1)(2x − 3)
  1. Misalkan u = x2 + 1 (u' = 2x) dan v = 2x − 3 (v' = 2).
  2. Rumus f' = u'v + uv' Turunan perkalian harus dijumlahkan, bukan dikalikan langsung.
  3. Substitusi= 2x(2x − 3) + (x2 + 1)(2)
  4. Sederhanakan= 4x2 − 6x + 2x2 + 2
Jawaban: f'(x) = 6x2 − 6x + 2

Cek dengan menjabarkan: f(x) = 2x3 − 3x2 + 2x − 3 → turunannya 6x2 − 6x + 2. Cocok.

Soal 4 — Turunkan f(x) = (2x + 1)/(x − 3)
  1. Misalkan u = 2x + 1 (u' = 2) dan v = x − 3 (v' = 1).
  2. Rumus f' = (u'v − uv') / v2
  3. Jebakan Penyebut dikuadratkan: (x − 3)2. Bukan (x − 3) saja.
  4. Substitusi= [2(x − 3) − (2x + 1)(1)] / (x − 3)2
  5. Sederhanakan= (2x − 6 − 2x − 1) / (x − 3)2
Jawaban: f'(x) = −7 / (x − 3)2
Soal 5 — Tentukan interval naik/turun dan titik stasioner f(x) = x³ − 6x² + 9x
  1. Turunan f'(x) = 3x2 − 12x + 9 = 3(x − 1)(x − 3)
  2. Titik kritisPembuat nol: x = 1 dan x = 3.
  3. Uji tanda Naik pada x < 1 atau x > 3; turun pada 1 < x < 3. Kesimpulan naik/turun diambil dari tanda f'(x), bukan dari nilai f(x).
  4. Nilai f(1) = 4 (maksimum), f(3) = 0 (minimum).
Jawaban: maksimum lokal di (1, 4), minimum lokal di (3, 0)
Soal 6 — Tentukan garis singgung f(x) = x³ − 2x di x = 1
  1. Nilai fungsi f(1) = 1 − 2 = −1 → titik singgung (1, −1).
  2. Gradien f'(x) = 3x2 − 2 → f'(1) = 1 Angka 1 inilah gradien yang masuk ke persamaan garis — bukan f(1) = −1.
  3. Susun y − (−1) = 1(x − 1)
Jawaban: y = x − 2

Glosarium

Turunan
Nilai limit gradien secan saat jarak dua titik menuju nol; gradien garis singgung.
Garis secan
Garis yang melalui dua titik pada kurva.
Garis singgung
Garis yang menyentuh kurva di satu titik dan searah dengan kurva di titik itu.
Diferensial
Istilah lain untuk turunan; juga merujuk pada proses menurunkan fungsi.
Titik stasioner
Titik dengan f'(x) = 0; kandidat maksimum, minimum, atau titik belok.
Maksimum lokal
Nilai tertinggi di sekitar titik tersebut, belum tentu tertinggi keseluruhan.
Laju perubahan
Seberapa cepat nilai fungsi berubah terhadap perubahan variabel bebas.
Biaya marginal
Turunan fungsi biaya total; perkiraan biaya tambahan per unit.
